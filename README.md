# comIA
CompIA est une interface web simple qui permet de présenter et de comparer les performances de différents assistants IA de programmation, notamment GitHub Copilot, Cursor AI et ChatGPT. Elle s'appuie sur des tests pratiques réalisés pour évaluer ces outils selon plusieurs critères, tels que la qualité du code, la rapidité, la précision et la facilité d'utilisation.
